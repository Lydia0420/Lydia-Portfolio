# Wind Chinese typography

`wind-serif.woff2` is a Noto Serif SC Regular subset built from this page's
text. Source: https://github.com/notofonts/noto-cjk/tree/main/Serif
License: SIL OFL 1.1, included at `../shared/fonts/graphic-serif-OFL.txt`.
Rebuild the subset when adding Chinese text; CSS includes a system fallback.
Only Chinese-mode supporting typography uses this asset. The English hero
title retains its original Aldrich and Georgia pairing.
