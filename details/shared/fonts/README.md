# Graphic family Chinese fonts

- `graphic-xiaowei.woff2`: ZCOOL XiaoWei Regular, sourced from https://github.com/google/fonts/tree/main/ofl/zcoolxiaowei
- `graphic-serif.woff2`: Noto Serif SC Regular, sourced from https://github.com/notofonts/noto-cjk/tree/main/Serif

Both use SIL OFL 1.1; the original license files are included alongside them.
These WOFF2 subsets contain the CJK characters used in the four graphic detail
pages at the time of this update. New Chinese copy may require rebuilding the
subsets; the CSS provides system fallback for characters outside them. Latin
headings continue to use the pages' existing Aldrich font.

XiaoWei is the experimental display choice for this version, not a replacement
claim for a commissioned reverse-contrast font. The editorial face is regular
Noto Serif SC; glyphs have not been artificially stretched or condensed.
